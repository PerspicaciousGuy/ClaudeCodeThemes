# Hearth

A warm theme: espresso browns by night, warm cream by day, a terracotta accent, and a slow dusk backdrop with a breathing sun, drifting haze and embers rising.

It follows your app's light or dark mode. The panels are frosted over the backdrop so text stays readable. Animations stop if your system asks for reduced motion.

![Hearth backdrop](../../docs/previews/hearth.png)

Install it from the repository README: `/plugin install hearth --marketplace PerspicaciousGuy/ClaudeCodeThemes`.
