# Risograph

Fluorescent pink, teal and yellow overprint on warm paper: a halftone sun with a ray burst, rolling hills, waves, stars and a cloud. Each ink layer drifts a few pixels so the print looks wet. The inks sit mostly at the edges.

![Risograph backdrop](../../docs/previews/risograph.png)

It is a light theme and keeps the app light. The panels are frosted over the scene so text stays readable. Animations stop if your system asks for reduced motion.

Install: `/plugin install risograph --marketplace PerspicaciousGuy/ClaudeCodeThemes` (see the [repository README](../../README.md#install) for the desktop app and shell steps).
