# Ukiyo-e Wave

A great wave curls on the left over scale-pattern swells that slide slowly across the sea. Small boats ride the water, foam flicks off the crest, a red sun hangs in a cream sky above a snow-capped mountain and birds cross. The sea at the right is calm so the middle stays open for the chat.

![Ukiyo-e Wave backdrop](../../docs/previews/ukiyo-e-wave.png)

It is a light theme and keeps the app light. The panels are frosted over the scene so text stays readable. Animations stop if your system asks for reduced motion.

Install: `/plugin install ukiyo-e-wave --marketplace PerspicaciousGuy/ClaudeCodeThemes` (see the [repository README](../../README.md#install) for the desktop app and shell steps).
