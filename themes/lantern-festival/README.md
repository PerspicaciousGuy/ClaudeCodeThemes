# Lantern Festival

Paper lanterns rise slowly into a starry sky above a still lake, their light shimmering on the water. A pagoda and hills stand in silhouette on the far shore. The lanterns keep to the sides so the middle stays open for the chat.

![Lantern Festival backdrop](../../docs/previews/lantern-festival.png)

It is a dark theme and keeps the app dark. The panels are frosted over the scene so text stays readable. Animations stop if your system asks for reduced motion.

Install: `/plugin install lantern-festival --marketplace PerspicaciousGuy/ClaudeCodeThemes` (see the [repository README](../../README.md#install) for the desktop app and shell steps).
