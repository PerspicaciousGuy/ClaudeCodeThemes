# Sakura Drift

A spring dusk. A pastel sky and a soft sun sit over layers of misty hills, and a blossoming tree on the left lets petals drift down, each swaying as it falls.

![Sakura Drift backdrop](../../docs/previews/sakura-drift.png)

It follows your app's light or dark mode. The panels are frosted over the scene so text stays readable. Animations stop if your system asks for reduced motion.

Install: `/plugin install sakura-drift --marketplace PerspicaciousGuy/ClaudeCodeThemes` (see the [repository README](../../README.md#install) for the desktop app and shell steps).
