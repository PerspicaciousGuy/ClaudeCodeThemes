# Circuit Board Calm

A calm version of [circuit-board](../circuit-board): the same scene, slowed to about 40% of its speed and softened under a veil, with heavier frosted panels behind the chat. It is for when motion or contrast pulls your eye away from the words.

![Circuit Board Calm backdrop](../../docs/previews/circuit-board-calm.png)

The colors are the same as circuit-board, so the app looks the same around it. Animations stop if your system asks for reduced motion.

Install: `/plugin install circuit-board-calm --marketplace PerspicaciousGuy/ClaudeCodeThemes` (see the [repository README](../../README.md#install) for the desktop app and shell steps).
