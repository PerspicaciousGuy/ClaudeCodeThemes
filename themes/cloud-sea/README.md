# Cloud Sea

A low sun rises over a sea of clouds. Rolling cloud banks drift slowly between dark mountain peaks, a few birds cross the sky and the sky fades from peach to blue. The sea of cloud fills the middle softly for the chat.

![Cloud Sea backdrop](../../docs/previews/cloud-sea.png)

It is a light theme and keeps the app light. The panels are frosted over the scene so text stays readable. Animations stop if your system asks for reduced motion.

Install: `/plugin install cloud-sea --marketplace PerspicaciousGuy/ClaudeCodeThemes` (see the [repository README](../../README.md#install) for the desktop app and shell steps).
