# New Year Fireworks Calm

A calm version of [new-year-fireworks](../new-year-fireworks): the same scene, slowed to about 40% of its speed and softened under a veil, with heavier frosted panels behind the chat. It is for when motion or contrast pulls your eye away from the words.

![New Year Fireworks Calm backdrop](../../docs/previews/new-year-fireworks-calm.png)

The colors are the same as new-year-fireworks, so the app looks the same around it. Animations stop if your system asks for reduced motion.

Install: `/plugin install new-year-fireworks-calm --marketplace PerspicaciousGuy/ClaudeCodeThemes` (see the [repository README](../../README.md#install) for the desktop app and shell steps).
