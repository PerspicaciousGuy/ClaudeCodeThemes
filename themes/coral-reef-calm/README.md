# Coral Reef Calm

A calm version of [coral-reef](../coral-reef): the same scene, slowed to about 40% of its speed and softened under a veil, with heavier frosted panels behind the chat. It is for when motion or contrast pulls your eye away from the words.

![Coral Reef Calm backdrop](../../docs/previews/coral-reef-calm.png)

The colors are the same as coral-reef, so the app looks the same around it. Animations stop if your system asks for reduced motion.

Install: `/plugin install coral-reef-calm --marketplace PerspicaciousGuy/ClaudeCodeThemes` (see the [repository README](../../README.md#install) for the desktop app and shell steps).
