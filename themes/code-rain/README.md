# Code Rain

Columns of falling glyphs in phosphor green, each with a bright head and a fading tail, set in your system monospace font. The columns under the chat are dimmer.

![Code Rain backdrop](../../docs/previews/code-rain.png)

It is a dark theme and keeps the app dark. The panels are frosted over the scene so text stays readable. Animations stop if your system asks for reduced motion.

Install: `/plugin install code-rain --marketplace PerspicaciousGuy/ClaudeCodeThemes` (see the [repository README](../../README.md#install) for the desktop app and shell steps).
